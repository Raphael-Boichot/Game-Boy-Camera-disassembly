# 20. TCRF's regional differences, item by item against the ROMs

The owner sent TCRF's page [Game Boy Camera/Regional Differences](https://tcrf.net/Game_Boy_Camera/Regional_Differences) (screenshots and a PDF, 2026-11-01). This file lists every difference that page describes and, for each, where the international ROM (`roms/us_eu/`) has it and what the disassembly says. It is the work list for the international ROM's text summary of differences.

Status: **located** (the ROM address and the code or table are named, tag C), **seen** (BGB screenshot), **known** (only TCRF so far), **open** (to look for).

Found by the disassembly and not on TCRF's page: the slide show ends on B only (Japan: A or B) and plays the first picture's P.VOICE (docs §1.5); the international credits table has 214 rows (Japan 234); the Gold edition's `Photo_RenumberVector` repairs a damaged photo order table (`roms/gold/README.md`).

Found by the L6 text pass (2026-11-02, `roms/us_eu/disasm/charset_us.csv`): the international name / comment font still holds the Japanese hiragana block (`$01-$55`) and the whole Japanese Latin block (`$C9-$F5`, code for code the Japanese glyphs), which no key of the international keyboard types; the Japanese third keyboard page (list C, Latin letters) is left in the ROM with its loader (`Unused_Kb_LoadGlyphSetC`, 09:54ED, no caller), and the two Japanese voiced-mark maps with their dead handlers; the font adds the accented letters, `ß`, `&` and a third face icon (a sad face, `$B8`), none of which the Japanese font has.
