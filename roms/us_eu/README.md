# Game Boy Camera (USA, Europe) (SGB Enhanced)

MD5 `42d2f65e2549be9d1d126a6828b5d1c1`. The international ROM: the same modes and states as the Japanese one in a different build (44.5 % of the bytes differ, mostly blocks moved by a fixed offset); the behavioural comparison with the Japanese ROM is in [`docs/16_menus_international_rom_bgb.md`](../../docs/16_menus_international_rom_bgb.md).

The symbol file is **ported from the Japanese tables** (method, counts and levels: [docs §1.5](../../docs/01_toolchain_and_status.md#15-the-international-rom-symbol-file-ported-from-the-japanese-one)):

| File | What it is |
|---|---|
| `gbcam_usa_eu.sym` | the mgbdis symbol file (generated by `tools/sym_build.py`; mgbdis reads it beside `gbcam_usa_eu.gb`) |
| `disasm/sym_names_us.csv`, `disasm/sym_types_us.csv` | names and type rows carried from the Japanese tables (generated by `tools/port_syms.py`: rerunning the port overwrites them) |
| `disasm/sym_names_us_loaders.csv`, `disasm/sym_types_us_loaders.csv` | blocks loaded by this build's own copy calls where no carried name sits (`tools/port_assets.py`) |
| `disasm/sym_names_us_hand.csv` | hand corrections and new names of this build, applied last (kept across re-ports): edit this one |
| `disasm/ram_names_us.csv`, `ram_exclude_us.csv`, `ram_highbyte_us.csv`, `const_*_us.csv`, `sound_names_us.csv`, `state_names_us.csv`, `state_helpers_us.csv` (+ `_hand`), `state_shared_us.csv`, `wram/wram_access_us.csv` | the L4 tables of this build (`tools/port_l4.py`, `tools/state_names.py`) |
| `src/` | the editable source tree (L5), generated by `tools/make_source.py --tree us_eu`; `make TREE=us_eu check` at the top of the repository builds it |
| `disasm/rom_operands_us.csv`, `disasm/rom_operands_manual_us.csv`, `port/cov_us.npz` | the ROM-address decisions of the tree, the hand ones, and the Japanese coverage carried through the maps that they use |
| `port/trace_us.json` | static trace of this ROM (`tools/rom_trace.py --config port/trace_config.json`), 0 unresolved |
| `port/code_map_us.csv` | Japanese instruction -> international instruction (same / operand / imm) |
| `port/map_segments_us.csv`, `port/map_inserted_us.csv` | the byte map as segments of constant shift, and the international bytes no Japanese byte maps to |
| `port/port_report_us.csv` | every Japanese name and where it went (or why not) |
| `port/hand_queue_us.csv` | what is left to do by hand: new code, lost names, names to check, untyped data |
| `port/trace_config.json`, `port/extra_roots.json`, `port/rom_trace_labels.sym` | the tracer inputs carried through the map |

Build the ROM from the tree: `make TREE=us_eu check` (rgbds 1.0.4 in `PATH` or `RGBDS=`). Regenerate the tree after a table change: `make source TREE=us_eu ROM=gbcam_usa_eu.gb`.

Rebuild everything (the ROM is not in the repository: owner's pack `source/Source_material/Source_material.zip`; rgbds 1.0.4 via `RGBDS=`):

```bash
python3 tools/port_build.py pocketcamera_jp.gb gbcam_usa_eu.gb --mgbdis /path/to/mgbdis.py     # md5 42d2f65e2549be9d1d126a6828b5d1c1 three times (plain, --tables, --const)
```

By hand, the listing:

```bash
cp gbcam_usa_eu.gb roms/us_eu/gbcam_usa_eu.sym build/
python3 mgbdis.py build/gbcam_usa_eu.gb --output-dir build/us --print-hex
D=roms/us_eu/disasm
python3 tools/sym_fix.py build/us --rom build/gbcam_usa_eu.gb --trace roms/us_eu/port/trace_us.json --tables --far-helpers 0473,049C,061B,068D,0734,0950,0956 \
  --const --ram-names $D/ram_names_us.csv --ram-access roms/us_eu/wram/wram_access_us.csv --ram-exclude $D/ram_exclude_us.csv --ram-highbyte $D/ram_highbyte_us.csv \
  --const-names $D/const_names_us.csv --const-types $D/const_types_us.csv --const-tables $D/const_tables_us.csv --const-sounds $D/sound_names_us.csv \
  --state-names $D/state_names_us.csv --state-helpers $D/state_helpers_us.csv --text-tables none
cd build/us && make && md5sum game.gb
```

The Japanese text tables and charmap are not applied (`--text-tables none`): this build's character set is not built yet.
