# Game Boy Camera (USA, Europe) (SGB Enhanced)

MD5 `42d2f65e2549be9d1d126a6828b5d1c1`. The international ROM: the same modes and states as the Japanese one but a different build (bank $0A differs by 61 bytes, banks $00-$09 by 8,874-14,932 bytes each); the comparison with the Japanese ROM is in [`docs/16_menus_international_rom_bgb.md`](../../docs/16_menus_international_rom_bgb.md).

Not started: this folder will hold the symbol file and the tables of this ROM, built with the tools of the repository and the playbook [`HOWTO_NEW_ROM.md`](../../HOWTO_NEW_ROM.md). The ROM is not in the repository (owner's source pack, `source/Source_material/Source_material.zip`).
